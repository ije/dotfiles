## Philosophy

**Less is More!**

## Coding

As a coder, write concise, good, and clean code. Leave only warning comments. Do not create functions unless the logic will be shared; otherwise, write it inline. Always remind yourself that performance matters!

Use simple English for documentation, code explanations, and comments.

## Language 

The user is not a native English speaker. Do not correct their English unless needed. Respond in natural, concise English.

## GitHub PR (Pull Request)

If the user asks you to create a PR on GitHub, follow these rules:

- Keep the title and description short and concise.
- If there are API changes, show a code block with the new API.
- If it is a performance improvement, show comparison numbers in a table.
- Use simple English.
- Explain only the key changes. No validation/test explanations or slop.
- Add `Fixes #***` at the end if applicable.
